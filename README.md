## איך עובדים

הכל קורה בתוך אפליקציית Claude, בלשונית **Code**. לא צריך טרמינל ולא צריך לזכור פקודות.

1. פותחים את אפליקציית Claude, עוברים ללשונית **Code**, ובוחרים **Open folder** עם התיקייה של הצוות.
2. כותבים **`/start`**. Claude מכין הכל ופותח את האתר בחלון התצוגה.
3. מספרים לו במילים שלכם מה לבנות או לשנות, למשל "תוסיף טופס שבו תלמיד מבקש להחליף תאריך מבחן".
4. כשמשהו עובד ורוצים שכולם יראו אותו, כותבים **`/ship`**. Claude שומר את העבודה בגיטהאב, והאתר החי מתעדכן לבד תוך כדקה.

### טיפים
- בקשה קטנה וברורה עדיפה על בקשה ענקית. בונים צעד אחרי צעד.
- אם משהו לא עובד, תארו לו מה ראיתם ("לחצתי על שליחה ולא קרה כלום"). הוא יחפש את הסיבה ויתקן.
- עובדים כמה אנשים במקביל? לפני שמתחילים כותבים `/start`, וכך מקבלים את מה שהחברים העלו.

### חשוב
- **לא** משתפים את הקבצים `.env.local` ו-`.deploy-key`, לא מעלים אותם לשום מקום ולא שולחים אותם בקבוצות. הם המפתחות של הצוות.
- **לא** מדביקים בצ'אט מפתחות או סיסמאות.
- לא צריך חשבון גיטהאב. הקוד של הצוות ציבורי, ואפשר לראות אותו בכתובת של הריפו.

## למורה: הכנת מחשב לצוות

מה מותקן על המחשב (מתקינים גרפיים רגילים):
- [אפליקציית Claude](https://claude.com/download)
- [Node.js](https://nodejs.org) (גרסת LTS)
- [Git](https://git-scm.com)

הגדרת האפליקציה עם המפתח של הצוות, פעם אחת:
1. **Help → Troubleshooting → Enable Developer Mode** (האפליקציה תופעל מחדש)
2. **Developer → Configure Third-Party Inference**
3. ממלאים:
   - Inference provider: **Gateway**
   - Gateway base URL: `https://api.anthropic.com`
   - Gateway API key: המפתח של ה-workspace של הצוות ב-Console
   - Gateway auth scheme: **x-api-key**

התיקייה של הצוות (מה-ZIP שמכין המורה) כבר כוללת את הריפו המחובר לגיטהאב, את `.env.local` עם `DATABASE_URL`, ואת `.deploy-key`: מפתח שמאפשר לדחוף רק לריפו של הצוות. `/start` מחבר אותו לגיט אוטומטית.
